# Deferred Accounting & Fiscal Modules (Phase 2+)

The following modules are fully implemented in the backend (`@corebiz/accounting`, `@corebiz/fiscal`, `apps/api`) and have Next.js routes under `apps/web/app/(app)/`, but are intentionally hidden from the sidebar navigation (`apps/web/src/ui/shell.tsx`) for the initial core release:

| Module                                                             | Web Route                    | Reason Deferred                                                                                                                      | When to Re-enable                                           |
| :----------------------------------------------------------------- | :--------------------------- | :----------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------- |
| **Bank Reconciliation** (`Conciliación Bancaria`)                  | `/accounting/reconciliation` | Bank account catalog & statement feeds are not yet configured in tenant settings.                                                    | Once bank accounts are added to Treasury/Settings.          |
| **Partner Drawings & Owner Consumption** (`Retiros & Autoconsumo`) | `/accounting/drawings`       | Combines equity cash drawings with inventory self-consumption; deferred to keep accounting focused on core sales/purchases/treasury. | When owner equity distribution workflows are required.      |
| **Forex Revaluation** (`Reexpresión (Forex)`)                      | `/accounting/forex`          | End-of-period unrealized FX revaluation (NIC 21 / VEN-NIF); active treasury conversions remain enabled via `/accounting/treasury`.   | When period-end closing routines are activated.             |
| **Fiscal Withholdings** (`Retenciones Fiscales`)                   | `/fiscal/withholdings`       | Required primarily for designated Special Taxpayers (`Contribuyentes Especiales` / US 1099).                                         | When tenant fiscal profile enables Withholding Agent mode.  |
| **Fiscal Sequence Ranges** (`Rangos y Vencimientos`)               | `/fiscal/sequences`          | Pre-authorized paper/digital invoice range alerts; deferred until digital printer/sequence enforcement is enabled per tenant.        | When formal SENIAT/DIAN sequence enforcement is toggled on. |
